## 二、创新点 2：预测式切换 PTHO + 星间认证上下文预迁移（降中断 / 降切换时延）

| 基线文献 | 核心做法 | 与本项目的缺口 |
|---|---|---|
| N. Badini, M. Jaber, M. Marchese, F. Patrone, "User-Centric Satellite Handover for Multiple Traffic Profiles Using Deep Q-Learning," **IEEE TAES**, vol. 60, no. 6, pp. 8591–8604, 2024. DOI:10.1109/TAES.2024.3434771 | 多智能体 DQN 切换，按多业务画像选星，HO 率↓60%、阻塞率↓91% | 依赖集中训练/复杂 DNN，**星上算力受限场景下不可落地**；且未解决"切换期认证重协商时延" |
| J. Wu, S. Su, X. Wang, J. Zhang, Y. Gao, "Accelerating Handover in Mobile Satellite Network," **IEEE INFOCOM 2024**, pp. 531–540. DOI:10.1109/INFOCOM52122.2024.10621115 | 利用星历**可预测轨迹**避免接入网—核心网交互，切换时延降 10× | 旗舰会议方案，验证"预测切换"有效性；但假设核心网可用，**不符合灾后核心网瘫痪约束**，且切换仍需重新认证 |
| L. Yang, X. Yang, Z. Bu, "A Conditional Handover Strategy Based on Trajectory Prediction for High-Speed Terminals in LEO Satellite Networks," **2024 IEEE ICC Workshops**, pp.1697–1701, 2024. DOI:10.1109/ICCWORKSHOPS59551.2024.10615358（★2026-09-23 联网核实） | 基于 GRU 轨迹预测的条件切换（PCHO），消除无线链路失败 | 预测服务于触发时机，未涉及**认证上下文随切换预迁移**（RACH-less 重连） |

**本项目增量**：继承 INFOCOM'24「星历预测切换」的核心思想，但将其约束改为**灾后无核心网、星上轻量化**；并新增**认证上下文星间预迁移**——目标星在切换前已持有终端凭证，新星一次比对即确认，把"重认证"从切换关键路径移除。

★归因更正（2026-09-16，消融臂实证）★：两项收益须分开陈述——
- **切换中断**：相对 Rel-17 反应式（380.5 ms）降至 **≈0**，归因于**预测提前量下的先建后断重叠窗**（20s ≫ 一次重连 ~381ms），**不是**预迁移；
- **切换时延**：相对"切后重认证"（381 ms）降至 **12 ms（↓97%）**，归因于**星间预迁移（RACH-less）**。

即本项目填补的空白是"**重认证拖慢切换时延**"，而非"重认证造成中断"；二者价值不同，须分别主张。

### 2.1 T2 对比矩阵落地（2026-09-16，Python/ns-3 双轨已实现）

对比方法收敛为 **5 基线（1 本职 + 2 业内 + 2 论文）+ 1 消融臂**：

| 类别 | `ho_policy` | 来源 | 选型判据 |
|---|---|---|---|
| 本职 | `predictive` | 本项目 | 星历预测 + 星间预迁移（RACH-less） |
| **消融臂** | `predictive_nopremig` | 本项目（**非基线**） | 与 `predictive` **同提前量/同候选选择**，仅**关闭**星间预迁移 → 分离「预测提前量」与「预迁移」两类收益 |
| 业内① | `cho` | 3GPP Rel-16/17 条件切换（TS 38.331） | 最广部署的近代切换标准 |
| 业内② | `rel17` | 3GPP Rel-17 NTN（反应式 + 四步 RACH） | 本方向**已落地**基线 |
| 论文① | `dqn` | N. Badini, M. Jaber, M. Marchese, F. Patrone, "User-Centric Satellite Handover for Multiple Traffic Profiles Using Deep Q-Learning," **IEEE TAES** 60(6):8591–8604, 2024. DOI:10.1109/TAES.2024.3434771 | 学习型——与本项目机制**正交** |
| 论文② | `graph` | S. Eydian, M. Hosseini, G. Karabulut Kurt, "Handover Strategy for LEO Satellite Networks Using Bipartite Graph and Hysteresis Margin," **IEEE OJCOMS** 6:1470–1484, 2025. DOI:10.1109/OJCOMS.2025.3541962 | 组合优化型——与本项目机制**正交** |

**实现忠实度（诚实披露）**
- `dqn` 为 **DQN 收敛策略的确定性等价**（非在线神经网络训练，亦非论文原方法的 **MADQN 集中训练/多智能体**）；仅作**机制对照**，不与论文做绝对数值比较。（★2026-09-22：Python 轨原另维护一张在线 Q 表 `qtab` 并以其作额外门控，而 ns-3 轨从未实现该表 → 两轨 dqn 语义不一致；已移除 Python 的在线门控，两轨统一为「安全提前量内、增益 ≥ λ 的候选中取最晚者」。）
- `graph` 在**本模型无卫星容量约束**的前提下，Kuhn-Munkres 最大权匹配在数学上退化为**加权 argmax**；其唯一可实现杠杆是「负载惩罚项 + 滞回边」，而负载项在本模型下**为弱归一、不 binding**（曾试改瞬时负载 + 峰值归一使其生效，实证净负面且致两轨发散，已撤回——见 `docs/技术决策确认.md` §3.5）。故 `graph` 定位为「负载感知加权匹配 + 滞回」的**近似实现**，非论文完整 KM 全局匹配。

**重要说明**：本表上方的 Wu INFOCOM 2024 与 2024 GRU-PCHO 虽为高等级/最新文献，但其机制为**预测式**，与本项目 `predictive` 同族；若选为对比基线，会被评审判为「本项目自己的消融实验」而非独立基线。故二者**仅作相关工作引述，不作对比基线**（★2026-09-23 已联网核实：GRU-PCHO 正确 DOI 为 `10.1109/ICCWORKSHOPS59551.2024.10615358`；原标注 `10.1109/10615358` 系截断、DOIs 系统查无此项——**已更正**）。

**消融臂的实证价值（★2026-09-16 由消融臂纠正的归因★）**

`predictive_nopremig`（同预测提前量、关闭预迁移）实测与 `predictive` **切换中断完全相同（均 ≈0.01 ms）**，仅**切换总时延**不同（**381.0 ms vs 12.1 ms**）、预迁移命中率 0（vs 1.0）。据此可把两项收益**干净分离**：

| 收益 | 归因机制 | 证据（双轨一致） |
|---|---|---|
| **切换中断 ≈ 0** | **预测提前量（先建后断，20s 重叠窗）**——20s 重叠远大于一次重连的 ~381ms，故中断被完全吸收 | `predictive` 与 `predictive_nopremig` 中断均 0.01 ms；`rel17`（反应式无提前量）中断 380.5 ms |
| **切换时延 ↓97%** | **星间认证上下文预迁移（RACH-less）**——把 ~381 ms 重连从关键路径移除 | 预迁移命中率 1.0/0.0；总时延 12.1/381.0 ms |

> ⚠️ **归因更正**：此前「预迁移使中断下降 ~100%」的表述**不准确**——中断归零来自**预测提前量**；预迁移的贡献是**压缩切换时延**（381→12 ms）。二者共同构成「先建后断 + 零重认证」的完整价值，但不可混为一项。

## 五、结论（用于答辩口径）

1. **两步 RACH 已被顶级期刊（TWC 2024/2025、WCL 2025）独立验证优于四步**——本项目在此基础上叠加"星历开环预补偿 + 应急突发 + 轻量认证"，属**场景化集成创新**而非重复造轮。
2. **预测式切换是 2024 年热点**（TAES 2024 DQN、INFOCOM 2024 星历预测 10× 降时延）——本项目的差异点是**灾后无核心网约束 + 认证上下文预迁移**，填补了"预测切换但重认证仍**拖慢切换时延**（381→12 ms）"的空白（中断归零由预测提前量提供，见 §2.1 归因更正）。
3. **优先级接入有 ICTC 2024 等近期工作**，但多为运营公平/定价视角；本项目的 **Kaufman-Roberts guard-channel 硬分级 + 与切换/认证联合**，是针对"救灾救人优先"语义的可证伪实现，且双轨（Python + ns-3）交叉验证一致。
4. 所有对照均为**可复现仿真**，未做无法核实的性能夸大；负向指标（低危吞吐）已显式建模为设计取舍。

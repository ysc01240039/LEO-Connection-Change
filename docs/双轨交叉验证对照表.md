### 3.1 T8 业务连续性（★2026-09-23 新增：双轨可比★）

契约自 2026-09-23 起含 `service` 列，**两轨均可按业务拆分**。以下为判别场景 `t8_stress`（短提前量，切换中断非零）的开关对照：

| 业务 | Python 轨（`--t8` 开 → 关） | ns-3 轨（`--t8PriorityOn` 1 → 0） | 一致性 |
|---|---|---|---|
| 话音 连续性满足率 | **1.000 → 0.8061** | **0.9995 → 0.8048** | ✅ 差 ≤0.001 |
| 图像 连续性满足率 | 0.9536 → 0.8179 | 0.9561 → 0.8189 | ✅ 差 ≤0.003 |
| 短信 连续性满足率 | 0.8967 → 0.8901 | 0.8954 → 0.9021 | ✅ 差 ≤0.012 |
| 总体满足率 | 0.9462 → 0.8366 | 0.9459 → 0.8415 | ✅ 差 ≤0.005 |

> **机理（两轨同参）**：业务感知给话音 / 图像 / 短信分别加 **12 / 4 / 0 s** 切换提前量（`config.T8_SERVICE_HO_LEAD_EXTRA_S`，
> C++ `t8LeadSec()` 逐行镜像），故**开启时话音中断被压到近零**（0.42 ms 对 552 ms）、满足率按业务单调分层；
> **关闭时三类收敛到同一量级**（~550 ms）。指标随机制开关单调响应 → 可证伪。
> run_id：Python `t8_stress_s20260901_r3_20260922T052043Z`（3 种子）；
> ns-3 `t8_stress_s20260901_ns3_20260923T143130Z`（开）/ `t8_stress_s20260901_ns3_20260923T143139Z`（关）。
> ⚠️ **注意区分度**：在 wenchuan / henan / storm2 / storm4 四个场景中，切换中断本就近零 → 三类业务满足率两轨**均为 1.0**（无区分度）；
> T8 的判别力来自 `t8_stress`（本表）。

## 4. 双轨一致性结论（2026-09-23 校对）

| 关键指标 | Python | ns-3 | 一致性 |
|---|---|---|---|
| 接入时延均值（常规 wenchuan / henan） | 12.24 / 11.49 | 12.25 / 11.48 | ✅ 差 ≤0.2% |
| 切换总时延均值（wenchuan，RACH-less） | 12.06 | 12.05 | ✅ 差 0.1% |
| 接入成功率（storm2） | 0.7050 | 0.7109 | ✅ 差 0.8% |
| 接入成功率（storm4） | 0.4455 | 0.4569 | ✅ 差 2.6% |
| 接入时延（storm4） | 652.8 | 669.5 | ✅ 差 2.6% |
| 预迁移命中率 | 1.0 | 1.0 | ✅ 一致 |
| 切换中断均值（wenchuan） | 0.02 ms | 0.0 ms | ✅ 同为「近零」 |
| 切换事件数（wenchuan） | 14805 | 15065 | ✅ 差 1.8%（位置采样随机性） |
| 伪造终端拦截率 | 0.9014 | 0.8387 | ⚠️ 差 6.3pp（见下） |

> **剩余小差异的根因**：① 双轨终端位置用**独立随机数流**采样（Python `Random(seed^0x5EED0000)` vs
> ns-3 内部 `random.Random(seed)`）→ 切换事件数、风暴成功率有小的统计浮动；
> ② 伪造拦截率差异来自**拥塞采样**——拦截率分母为「进入认证环节的伪造终端」（契约 §2.1），
> 拥塞下双轨的伪造终端到达/重试序列不同，故占比有浮动（两轨均 ≈0.84–0.90，量级一致）。
> 均为**随机实现差异，非口径或逻辑差异**——双轨同参、同结论已达成。

## 6. 星间认证上下文预迁移对照（单变量，★由消融臂给出★）

| 指标 | `predictive`（预迁移开） | `predictive_nopremig`（预迁移关） | 变化 |
|---|---|---|---|
| 切换总时延均值 | 12.06 ms | 381.0 ms | **↓ 96.8%** |
| 预迁移命中率 | 1.0 | 0.0 | — |
| 切换中断均值 | 0.01 ms | 0.01 ms | **无变化**（见下） |

> ★**归因更正（2026-09-16）**★：消融臂实测两者**切换中断完全相同**，故——
> **中断归零来自「预测提前量下的先建后断重叠窗」**（20s ≫ 一次重连 ~381 ms），
> **预迁移的贡献是压缩切换时延（381→12 ms，↓96.8%）**。
> 原「预迁移使中断下降 ~100%」的表述不准确，已在 `docs/学术基线对照.md` §2.1 与
> `docs/技术决策确认.md` §3.1 更正。权威表：[`perf/crossval_ho_table.txt`](../perf/crossval_ho_table.txt)。
> **来源/种子说明（2026-09-23 补注）**：本表 `predictive` 的 12.06 ms 取**主实验 run**（seed 20260901，同 §2/§4，run_id 见 `results/wenchuan_metrics.json`）；`predictive_nopremig` 的 381.0 ms 取 **T2 消融矩阵**（crossval seed 42）。矩阵同表内 `predictive` 行作 12.14 ms（seed 42），与本行 12.06 ms 的差异来自终端位置采样种子，**结论一致（↓96.8%）**。
> **10 种子独立核验（2026-09-23 补注）**：同批 `--reps 10`（seed 20260901 起 10 个独立种子）受控对照下，**Rel-17 四步基线**切换总时延 **380.91 ± 0.02 ms**、**本方案** **12.06 ± 0.007 ms**（↓96.8%）——与本行消融臂（381.0 / 12.06）一致。产物：`results/多种子统计_storm2_10seed_20260923.json`。

### 3.1 双轨一致性结论（P1/P2 修正 + ns-3 补齐后）

| 关键指标 | Python | ns-3 | 一致性 |
|---|---|---|---|
| 接入时延均值（常规 wenchuan/henan） | 12.27 / 11.51 | 12.25 / 11.49 | ✅ 逐位一致 |

| 乒乓切换率 | 0.0 | 0.0 | ✅ 一致 |
| 假名轮换次数 = 切换数 | 14116 = 14116 | 14876 = 14876 | ✅ 语义一致（每次切换轮换） |
| 接入成功率（风暴） | 0.439 / 0.432 | 0.723 / 0.708 | ⚠️ 绝对值不同（见下） |

> **风暴场景绝对值差异（诚实标注，非 bug）**：接入成功率 Python 0.439 vs ns-3 0.723，根因是**终端空间分布口径不同**——Python 轨为单参考点（灾区中心，所有终端共享可见窗），ns-3 轨为每终端独立位置（中心 ±0.6° 均匀分布）；切换事件数（14116 vs 14876）同理。**方向性结论**（两步优于四步、生存优先增益、预测式切换中断趋零、预迁移效果）双轨一致。

## 4. 双轨一致性结论（方案A 同参后）

| 关键指标 | Python | ns-3 | 一致性 |
|---|---|---|---|
| 接入时延均值（常规 wenchuan/henan） | 12.26 / 11.51 | 12.25 / 11.49 | ✅ 逐位一致 |
| 切换总时延均值（wenchuan） | 12.02 | 12.02 | ✅ 逐位一致 |
| 接入成功率（storm2） | 0.713 | 0.7225 | ✅ 差 1.4% |
| 接入成功率（storm4） | 0.705 | 0.7075 | ✅ 差 0.4% |
| 接入时延（storm4） | 583.1 | 590.5 | ✅ 差 1.3% |
| 预迁移命中率 | 1.0 | 1.0 | ✅ 一致 |
| 假名轮换次数 = 切换数 | ✅ | ✅ | ✅ 语义一致 |
| 切换事件数（wenchuan） | 14221 | 14876 | ✅ 差 4.4%（位置采样随机性） |

> **剩余小差异的根因**：双轨终端位置用**独立随机数流**采样（Python `Random(seed^0x5EED0000)` vs ns-3 `RngStream`），
> 位置点不完全相同 → 切换事件数、风暴时延有小的统计浮动；接入时延逐位一致（几何决定时延，位置差异影响小）。
> 这是**随机实现差异，非口径或逻辑差异**——双轨同参、同结论已达成。

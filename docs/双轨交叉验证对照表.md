## 3. 双轨一致性与差异分析（诚实报告）

### 3.1 完全同构的部分（常规场景，误差可忽略）

- 接入成功率：双轨均为 1.0000（wenchuan / henan，容量充足）。
- 接入时延：wenchuan 13.14 vs 13.15 ms；henan 12.39 vs 12.37 ms（差 <0.02 ms）。时延由 2×传播时延（真实斜距/光速）+ 星上处理构成，几何计算双轨同源（skyfield vs ECEF 插值，差 <0.5%）。
- 切换中断：均值为 0 且最大值为 0（先建后断无中断，验证「驻留稳定优先 + 覆盖重叠」判决使中断被消除）。
- 乒乓切换率：双轨均为 0（候选必须晚于服务星 LOS 且剩余可连 >60 s 才入选）。
- 伪造终端拦截率：双轨均为 1.0000（星上凭证校验全部拦截）。
- 风暴四步附加时延：双轨均为精确 +400.0 ms。

### 3.2 统计性差异（风暴场景，成因明确、非系统性偏差）

- 风暴场景接入成功率：Python 0.6454 vs ns-3 0.8194；风暴 P95 时延 1012.75 vs 929.33 ms。
- 成因：双轨使用独立随机数流（Python 内建 `random`（种子 20260901）vs ns-3 `RngStream`），终端到达时刻与退避量抽样顺序不同。在容量饱和（4/10 ms）下，退避-重试-碰撞形成强非线性决策树，抽样实现的微小差别被逐级放大为成功率与时延分布的整体浮动。属**随机实现差异**而非口径或逻辑差异——证据是默认场景（退避不发生）下双轨核心指标逐位一致；风暴四步/两步的相对行为双轨一致（成功率均不变，时延均 +400 ms）。
- 误码/拥塞的确定性对比建议：如需要逐位可比结果，可采用共享随机种子方案（把终端到达时刻/退避量预先写入输入文件，双轨同读），列为后续可选项。

### 3.3 其余小差异说明

- 伪造终端数（72 vs 48；53 vs 35）：5% 占比下独立二项式抽样之浮动，拦截率不受影响。
- 切换事件数（9024 vs 9216；5824 vs 7552）：由终端到达抽样不同导致的服务时长链长度浮动，次级影响（正常）。
- 预测失配率双轨均接近 1：高密度 LEO 星座下「稳定优先」选星与 LOS 时刻「仰角最优」系统性不一致，本文按契约如实报告，作为后续改进（更长提前量/迟滞/仰角-窗口联合优化）的量化依据。

## 阶段一：首联发证（MsgA / MsgB 两步）

### 消息字段布局（Q6 提议：方向 C 下 MsgA 内嵌认证/业务字段）

```
MsgA (UE → Sat, 两步接入首帧，含 RACH 前导 + 载荷):
  preamble_group   : 优先级分组号 (高优先级专用分组, T3分组调度)
  dev_id           : 设备根身份 (出厂/eSIM 预置, Q4 终端侧根)
  dev_sig          : Sign_{dev_key}( nonce_sat || dev_id )   <<Q1 已决议: 设备根签名同族 EC-Schnorr>>
  gnss_pos         : GNSS 位置 (开环预补偿用)
  ta_est           : 终端自估 TA (基于星历)
  doppler_est      : 终端自估多普勒补偿
  prio             : 业务优先级 (1/2/3)
  danger           : 危险度标签 (0..3, 来自 T2)
  nonce_ue         : 终端随机数

MsgB (Sat → UE, 确认 + 发证):
  issue_ts         : 星上时钟
  sat_issue_id     : 本星 ID
  tid              : 新假名/临时标识                  <<Q2 已决议: 每次切换轮换>>
  clc_partial      : CL-PKC 部分私钥 (星作为在轨 KGC 下发)  <<Q1 已决议: EC-Schnorr CL-PKC>>
  hash_seed        : 哈希链种子 (首联下发)             <<Q3 已决议: 星 MsgB 下发>>
  hash_idx         : 0
  pseudo_epoch     : 0
  sig              : Sign_{kid}( tid||hash_seed||issue_ts||sat_issue_id )  <<Q5 已决议: 复用星座根 kid (EC-Schnorr)>>
  ta_corr          : 残余 TA 校正 (预补偿反馈)
```

### 卫星侧伪代码（首联）

```
on RACH_REQ(ue):
  if ue.preamble_group collides:                       # T3 分组+退避
      schedule_retry(ue); emit RACH_REQ COLLIDE; return
  if not disaster_confirmed:                           # Q4: 星侧探测信关不可达
      disaster_confirmed = probe_gateway_unreachable() # 星侧可观测量, 非终端自述
  if not verify(dev_sig, dev_id):                      # 设备根身份校验 (R1 授权根)
      emit AUTH_DEV_ID_FAIL; reject(ue)                 # → 伪造终端拦截率
      return
  ctx = AuthContext(
      dev_id, tid=gen_pseudonym(), kid, sat_issue_id=self.id,
      issue_ts=now(), cred_state=ISSUED, hash_seed=gen_seed(),
      hash_idx=0, pseudo_epoch=0, prio, danger,
      disaster_confirmed, ta_resid=calc_resid(ta_est,ta_corr))
  issue CLC partial + sign envelope (kid)
  emit AUTH_DEV_ID_OK, CRED_ISSUE
  send MsgB(ctx)
```

### 终端侧伪代码（首联）

```
send MsgA(dev_id, dev_sig, gnss_pos, ta_est, doppler_est, prio, danger, nonce_ue)
wait MsgB:
  store tid, clc_partial, hash_seed, hash_idx, pseudo_epoch
  apply ta_corr; ctx.cred_state = ISSUED
  if ta_resid > THRESH_TA:                              # Q8: 预补偿失败
      fallback_to_4step()                               # 回退四步, 统计入 p95
```

# T5: 基于星历预测下一可连卫星
predict_target = predict_next_visible(ctx.gnss_pos, ephemeris, now())

# T6: 双条件判决 (Q12 阈值扫参)
remaining_vis = visible_time_left(self, ue)
stable = snr_stability(ue) > STABILITY_THRESH_DB
if remaining_vis < T_HANDOVER_S and stable:
    prepare_token(ue)        # 进入先建后断

# 准备 TokenEnvelope (终端携带, 不依赖 ISL)
token = TokenEnvelope{
    tid, sn=++ctx.sn, predict_target, hash_idx=ctx.hash_idx,
    issue_ts, sat_issue_id,

ctx.token_env = token

## 阶段三：切换重连一次比对（T7 / T8）

### 终端侧（切换重连，复用两步接入字段）

```
send MsgA_handover(tid, token_env, prio, danger, predict_target, nonce_ue)
```

### 目标星侧伪代码（一次比对）

```
on HANDOVER_MSG(ue):
  tok = ue.token_env
  if tok.predict_target != self.id:                    # 预测失配兜底
      emit PREDICT_MISMATCH
      fallback_reissue(ue)                             # 退化为重新发证 (R3 预期行为)
      return
  if not verify_sig(tok.sig, kid):                     # 星座根直验, 无需 ISL (R3)
      reject(ue); return
  if tok.sn <= cached_sn(tid) or tok.hash_idx <= cached_idx(tid):  # 防重放 (R6)
      reject(ue, REPLAY); return
  # 一次比对即确认, 跳过完整认证
  ctx = load_or_init(tid); ctx.sn=tok.sn; ctx.hash_idx=tok.hash_idx
  ctx.cred_state = ISSUED
  emit HANDOVER_TOKEN_VERIFY OK, HANDOVER_OK
  # T8: 业务连续 — 按 prio 恢复承载 (v1 仅安全上下文, 承载见 Q11)
  resume_bearer(ue, prio)
```

## 一、Q6 / Q9 落地提议（实现骨架，可调）

- **Q6 字段布局**：上表 MsgA/MsgB 已含方向 C 首次发证所需的 `dev_id/dev_sig/clc_partial/hash_seed` 扩展字段，与 `仿真接口约定.md` §一 AuthContext 字段一一对应。
- **Q9 令牌时序复用**：切换重连 `MsgA_handover` 直接复用首联 `MsgA` 的 `(tid, prio, danger, nonce)` 字段，仅增 `token_env` + `predict_target`——"一套协议管两件事"。

## 二、人定占位清单（算法已决议，实现细节仍由人主导）

| 占位 | 决策点 | 决议 | 影响字段 |
|---|---|---|---|
| `<<Q1>>` | CLC/CL-PKC 构造 + 设备根签名 | **EC-Schnorr CL-PKC**；星=在轨 KGC 仅持主公钥+下发部分私钥，主私钥不传星 | `clc_partial`, `dev_sig` |
| `<<Q2>>` | 假名轮换触发 | **每次切换轮换**（前向不可关联，令牌自带新 tid） | `tid`, `pseudo_epoch` |
| `<<Q3>>` | 哈希链种子来源/索引方向 | **首联 MsgB 下发种子 + 索引单向递增**；星上 (tid→idx,sn) 轻量表 LRU+超时 | `hash_seed`, `hash_idx` |
| `<<Q5>>` | 令牌/发证信封签名 | **复用星座根 kid** 签名（任意目标星直验，v1 不加密） | `sig`, `TokenEnvelope.sig` |

## 三、其余实现参数提议（Q7/Q8/Q10/Q11/Q12，已提默认待最终确认）

- **Q7** 危险度×业务优先级：字段已定（`prio` 1/2/3、`danger` 0..3），**提议默认**聚合 `weight = prio*4 + danger`（→4..15，越大越先接入），由 T3 调度模块实现。
- **Q8** 预补偿失败回退：**提议默认**残余 TA 误差 `ta_resid > THRESH_TA`（初值 = 1/4 循环前缀）回退四步，事件记 `ACCESS_STEP4_FALLBACK`，计入 p95 与接入成功率分母。
- **Q10** 预测失配：`PREDICT_MISMATCH` 事件 → 指标「预测失配率」= 失配数/总切换数；失配走 `fallback_reissue` 退化重新发证。
- **Q11** 承载上下文：**提议默认** v1 仅安全上下文（令牌），业务连续靠重叠窗；承载上下文（PDCP 序号等）留第二阶段。
- **Q12** 判决阈值：**提议默认** `T_HANDOVER_S=5s`、`STABILITY_THRESH_DB=3dB`，作为 ns-3 扫参变量。

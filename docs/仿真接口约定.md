## 一、统一认证上下文数据结构（Q13 · T3 生成 / T4 填充 / T5~T8 迁移 / T11 统计）

> 这是三栈共用的核心数据结构。逻辑上"挂在终端身上、由服务星维护、切换时由终端携带令牌交给目标星"。
> 星上只存轻量索引表 `(tid → 上下文摘要)`，不 Whole 存明文。

### 1.1 AuthContext（每终端一条，逻辑结构）

| 字段 | 类型 | 含义 | 由谁填写 | 对应决策 |
|---|---|---|---|---|
| `dev_id` | opaque hash | 设备根身份（出厂/eSIM 预置，**非卫星运营凭证**） | 出厂预置 | Q4 双根·终端侧根 |
| `tid` | string | 当前假名/临时标识（匿名化，随轮换更新） | 首联发证时生成 | Q2 假名轮换 |
| `kid` | uint | 星座根密钥 ID（用于验令牌） | 卫星发射前烧入 | Q4 双根·卫星侧根 |
| `sat_issue_id` | uint | 下发当前凭证的卫星 ID | 首联发证星 | Q4 |
| `issue_ts` | uint(ms) | 发证时星上时钟 | 发证星 | Q4 |
| `cred_state` | enum{NONE,ISSUED,EXPIRED} | 凭证状态 | T4 | 方向 C |
| `hash_seed` | bytes | 哈希链种子（首联发证时由星上下发） | 发证星 | Q3 |
| `hash_idx` | uint | 当前哈希链索引（单调，单向） | T4/T7 | Q3 |
| `pseudo_epoch` | uint | 假名轮换计数 | T4 | Q2 |
| `prio` | enum{1,2,3} | 业务优先级：1 指挥话音 / 2 灾情图像 / 3 报平安 | 场景包(T2) | T3 |
| `danger` | uint{0..3} | 位置危险度标签（被困/指挥/伤员…） | 场景包(T2) | T3 |
| `disaster_confirmed` | bool | 星侧探测信关不可达→进入灾区模式 | 服务星 | Q4 |
| `ta_resid` | float | 开环预补偿后 TA 残余误差（判定两步/四步） | T3 | T3 |
| `predict_target` | uint | 星历预测的下一颗可连卫星 ID | T5 | T5 |
| `sn` | uint | 上下文序号（单调，令牌新鲜度/防重放） | T4/T7 | Q3/R6 |
| `token_env` | bytes | 切换令牌信封（见 1.2，终端携带） | T4/T7 | 终端携带令牌 |

### 1.2 TokenEnvelope（终端携带的切换令牌，喂 T7 一次比对）

```
TokenEnvelope = {
  tid, sn, predict_target, hash_idx, issue_ts, sat_issue_id,
  sig = Sign_{kid}( tid || sn || predict_target || hash_idx || issue_ts || sat_issue_id )
}
```
- **签名密钥**：签发星的星座根密钥（`kid` 索引）。目标星用 `kid` 对应的星座根**直接验**，无需 ISL、无需实时告知邻居（解决 R3）。
- **防重放**：目标星校验 `sn` 单调 + `predict_target` 一致；`hash_idx` 单向递增（解决 R6）。
- **预测失配兜底**：若 `predict_target ≠ 实际服务星` → 判「预测失配」，令牌作废，退化为重新发证（呼应「预测失配率」）。

### 1.3 字段流动图

```
T2 场景包 ──(prio,danger)──┐
T0 出厂预置 ──(dev_id)──────┤
                            ▼
        [首联] T3+T4：终端直连 → 星确认 disaster_confirmed(信关不可达)
              → 终端出示 dev_id → 星校验 → 星下发 {tid, hash_seed, hash_idx=0, issue_ts, sat_issue_id}
                            │
                            ▼
        AuthContext.cred_state = ISSUED
                            │
        [切换] T5 预测 predict_target → T7 终端携 TokenEnvelope 给目标星
              → 目标星用 kid 直验 sig + 比对 sn/hash_idx/predict_target
              → 一次比对即确认（跳过完整认证）
```

## 三、仿真 Trace 接口（ns-3 → Python，CSV）

> 每一行一条事件；Python 解析后统计 §〇 指标。字段顺序固定，缺失填 `-`。

```
event_id, timestamp_ms, event_type, ue_id, sat_id, target_sat_id, prio, danger, result, detail
```

| event_type | 触发点 | result 取值 | 贡献指标 |
|---|---|---|---|
| `RACH_REQ` | 终端发前导 | `COLLIDE` / `OK` | RACH 吞吐量、接入成功率 |
| `ACCESS_STEP2_OK` | 两步接入成功 | `OK` | 接入时延、接入成功率、认证引入额外时延 |
| `ACCESS_STEP4_FALLBACK` | 预补偿失败回退四步 | `OK`/`FAIL` | 接入时延(p95)、成功率 |
| `AUTH_DEV_ID_OK` | 设备根身份校验过 | `OK` | 认证引入额外时延 |
| `AUTH_DEV_ID_FAIL` | 设备根身份校验不过（伪造） | `REJECT` | **伪造终端拦截率** |
| `CRED_ISSUE` | 星上下发运营凭证 | `OK` | 认证引入额外时延 |
| `HANDOVER_PREDICT` | T5 预测目标星 | `OK` | 预测失配率（与后续比对） |
| `HANDOVER_TOKEN_VERIFY` | T7 验令牌 | `OK`/`MISMATCH` | 预测失配率、切换成功率 |
| `HANDOVER_OK` | 切换完成 | `OK` | 切换中断时间、切换成功率 |
| `HANDOVER_FAIL` | 切换失败 | `FAIL` | 切换成功率 |
| `PINGPONG` | 乒乓切换 | `FAIL` | 乒乓切换率 |
| `PREDICT_MISMATCH` | 预测目标≠实际 | `MISMATCH` | 预测失配率 |

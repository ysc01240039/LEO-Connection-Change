# 仿真接口约定（三栈契约 · 可替换 / 可审计）

> 配套代码：
> - `run_ns3.py`：主驱动，一键完成 TLE→ECEF→ns-3→trace→指标→图表→报告。
> - `.ns3_ref/leo_access.cc`：ns-3 scratch 协议实现（L3）。
> - `sim/ns3_io.py`：Python 侧供数 / 回采 / 覆盖度。
> - `sim/viz.py`：中文图表与 HTML 报告。
>
> 本文档是 ns-3 / Python / Web 三栈的**唯一接口权威**，字段写死；改字段须同步三栈。

### 1.3 `ephemeris.csv` 表头


## 2. 仿真 trace CSV（ns-3 → Python，★核心契约★）

文件：`data/sim/ns3_out/access_trace.csv`

表头（字段顺序固定）：

| 列 | 类型 | 含义 |
|---|---|---|
| `event_type` | enum | `ACCESS` / `HANDOVER` |
| `terminal` | int | 终端编号（CSV id，0..n_terminals-1） |
| `tag` | enum | `high` / `med` / `low` |
| `t_s` | float | 事件发生时刻（相对起点秒） |
| `serving_sat` | int | 服务星节点 id（ACCESS 时即接入星） |
| `target_sat` | int | 切换目标星节点 id（HANDOVER 时） |
| `value_ms` | float | ACCESS 为接入时延(ms)；HANDOVER 为切换中断(ms) |
| `doppler_hz` | float | 事件时刻多普勒(Hz，可负) |
| `slant_km` | float | 事件时刻斜距(km) |
| `result` | enum | `success` / `fail` |
| `predict_mismatch` | bool | 预测失配标记（0/1） |
| `pingpong` | bool | 乒乓切换标记（0/1） |
| `ho_el_cost_deg` | float | 仰角代价（°）：执行时刻仰角最优星瞬时仰角 − 选中星瞬时仰角（仅 HANDOVER 有效） |
| `forged` | bool | T4 伪造终端标记（0/1；星上 dev_sig 校验失败 → 拦截，事件 result=fail） |

### 2.1 指标口径（与报告一致）

- **接入成功率** = 合法终端成功接入数 / 合法终端接入事件数（伪造终端不计入分母，其拦截情况由「伪造终端数 / 伪造终端拦截率」单独汇报）。
- **接入时延** = (GRANT 完成时刻 − 终端首次发起时刻)×1000（ms），**端到端**口径：含碰撞退避/可见性等待与两步（或四步）握手全程；仅统计成功接入的合法终端（`value_ms > 0`）。常态无拥塞时退避项≈0，时延≈2×传播时延+星上处理+认证/四步附加。
- **伪造终端数 / 伪造终端拦截率** = 伪造终端接入事件数 / 其中被星上凭证校验拒绝（result=fail）的占比。
- **切换中断** = `max(0, 新链确认时刻 − 旧链丢失时刻)`；均值为 0 表示“先建后断”成功。
- **乒乓切换率** = 候选星剩余可见时间 `< 60s` 的 `HANDOVER` 占比（反映切换稳定性）。
- **预测失配率** = 在候选星自身丢失时刻，候选星不再是仰角最优可见星的 `HANDOVER` 占比；衡量基于星历预测的窗口尺度最优性。高密度 LEO 星座下贪婪策略此值偏高，改进方向为更长提前量 / 迟滞 / 仰角-窗口联合优化。
- **仰角代价（均值/最大）** = `ho_el_cost_deg` 的统计量（°）；量化“稳定优先（驻留最长）”相对“仰角最优”的实质牺牲，诚实汇报。

## 5. 数据源溯源与建模边界（审计用）

- **真实数据**：星座 TLE 来自 Celestrak（`provenance.url`），抓取时间入档；可见窗 / 多普勒 / 时延为 `TLE + skyfield` 真实计算，无硬编码。
- **建模边界（诚实声明）**：
  1. 终端数、突发强度、危险度分布：`scenario.py` 设定（仿真输入，非外场实测）。
  2. 本 ns-3-dev **未安装 `satellite` / `nr` 模块**，链路层为**自定义 LEO 信道**（应用层承载 `ns3::Packet` 并按传播时延调度投递），非 3GPP NTN 物理层。
  3. T4 认证仅建模**外部队列开销与拦截结果**（星上轻量凭证校验附加时延 `auth_extra_ms` + 伪造终端按 `forged_ratio` 抽样、`dev_sig` 校验失败即拦截），密码原语内部计算不在仿真内实现；碰撞/拥塞模型为**星上按 10ms 时间片限流**（`rach_capacity` 前导码受理上限）+ 终端均匀随机退避重试（`retry_interval_ms`/`retry_max`）。
  4. 两步/四步 RACH 的差异仅建模为**星上处理附加时延**（`rach_steps`、`step4_extra_ms`：RAR 等待+竞争解决），未建模随机接入前导码级碰撞（PLMN 级拥塞以限流呈现）。
  5. 仿真值为既定场景假设下的结果，**非外场实测**。
- **绝不**：把仿真值伪装为实测值；无源数据直接拒收。

## 5. 客观风险提示

1. **审计前那几个"完美数字"（100% 成功率、0ms 中断、0 乒乓、100% 拦截）确属构造保证，已拆除**。现指标均为仿真产物，可被参数扫描推翻——这正是答辩需要的"可证伪性"。
2. **拦截率 0.83 非满分**：因建模了"密钥泄露型伪造终端"（持有合法凭证，密码层不可检出，属漏检）。若答辩要求更高拦截率，需补充"行为/异常检测"或"星上凭证在线吊销"，属计划书范围外扩展。
3. **Eb/N0 / 误码为建模假设**（EIRP/G-T/速率在 `config.py` 显式列出并可扫描），并非 3GPP NTN 物理层实测；已在溯源表标注。
4. **ns-3 未装 satellite/nr 模块**：链路层为自定义 LEO 信道（应用层 NetDevice），非比特级 NTN 物理层；接口（trace 字段）不变，后续可替换 `LeoChannel`。
